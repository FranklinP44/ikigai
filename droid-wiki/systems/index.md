# Systems

Two internal building blocks sit underneath the [features](../features/index.md).

| System | Responsibility | Page |
| --- | --- | --- |
| Region rendering | Builds SVG masks so each of the 13 zones can be painted and highlighted on its own | [Region rendering](region-rendering.md) |
| Visual design | Design tokens, typography, entrance animations, and responsive layout in CSS | [Visual design](visual-design.md) |

Region rendering is JavaScript that runs once at page load. Visual design is pure CSS and applies continuously.
