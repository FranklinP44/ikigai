# Lore

The repository is young: seven commits on `main` between 25 Sep and 8 Oct 2026. This page records how it got from a three-file static page to a TypeScript and Vite project with two CI workflows.

## Eras

### The first drop (Sep 2026)

On 25 Sep 2026, the complete app landed in a single commit, "feat: add interactive four-circle Ikigai diagram" (`07f52b9`). It added `index.html`, `script.js`, and `styles.css` together, 404 lines in total, with no build step and no package manager. GitHub Pages served the files straight from the root of `main`. The commit carries a `Co-authored-by: factory-droid[bot]` trailer, so it was built with help from Factory's Droid agent.

There is no earlier prototype in the history. The polish already present in that first commit (staggered entrance animations, anti-aliased mask regions, a phone breakpoint, and an `aria-live` panel) suggests the design was iterated on before it was committed.

### The wiki and Confluence publishing (Oct 2026)

On 6 Oct 2026, commit `005b4e0` added this wiki: 29 pages under `droid-wiki/`, generated by Factory's `/wiki` command from commit `07f52b9`. The same commit added `.github/workflows/publish-wiki-to-confluence.yml` and `.github/scripts/publish_confluence.py`, which convert the Markdown to Confluence storage format, render Mermaid diagrams to PNG, and mirror the folder tree into the IKIGAI Confluence space. Pull requests get a dry run; merges to `main` publish. It was merged as PR #1 (`1cb2006`) the same day.

The publishing script is 535 lines, larger than the whole original app.

### TypeScript, Vite, and Pages via Actions (Oct 2026)

The migration was written on 1 Oct 2026, on a local branch, before the wiki existed on `main`:

- `34e4642` (1 Oct 2026) ported `script.js` to strict TypeScript modules `src/data.ts`, `src/geometry.ts`, and `src/main.ts`, moved `styles.css` to `src/styles.css` unchanged, and added `package.json`, `package-lock.json`, `tsconfig.json`, and a `README.md`.
- `1cbff8c` (1 Oct 2026) added `allowScripts: { fsevents: false }` to `package.json`, blocking the optional fsevents install script because the package ships a prebuilt binary.

Both commits carry the `factory-droid[bot]` co-author trailer. On 8 Oct 2026 the branch was rebased onto `main`, which is why their committer dates read 8 Oct. Commit `8f8358f` (8 Oct 2026) then set Vite's `base` to `'./'` in `vite.config.ts` so asset URLs work under the `/ikigai/` Pages subpath, and added `.github/workflows/deploy-pages.yml`, which builds on every pull request and deploys `main` to GitHub Pages. The branch `migrate/ts-vite` was merged as PR #2 (`e878c1f`) on 8 Oct 2026, and the Pages source was switched from the `main` branch root to GitHub Actions. Details are in [Deployment](deployment.md).

The port was 1:1. The live site looks and behaves the same as before.

## Origins of the model itself

The app's own footnote in `index.html` records the backstory of the diagram it draws: Andrés Zuzunaga created a purpose Venn diagram, and in 2014 Marc Winn relabeled it as "ikigai". In Japan, ikigai more broadly means whatever makes life feel worth living. More trivia is in [Fun facts](fun-facts.md).
