# Background

Why the code is shaped the way it is, and where it is easy to trip.

- [Design decisions](design-decisions.md): masks over clip-paths, geometric hit testing, no framework, the TypeScript + Vite migration, and how the content is framed.
- [Pitfalls](pitfalls.md): duplicated geometry, `innerHTML`, coupled timings, keyboard reachability, and build and deployment traps such as the Vite base path and opening `dist/index.html` from disk.
